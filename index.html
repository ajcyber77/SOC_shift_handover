Connect to shared database

This app stores data on JSONBin.io (free) so your whole team shares the same history. Every team member just needs the same API key — the database is found automatically.

1
Go to jsonbin.io and create a free account (or ask your admin for the team API key).
2
Click API Keys in the left sidebar and copy your Master Key (starts with $2b$…).
3
Paste the key below and click Connect. If a shared database already exists it connects automatically — otherwise it creates one.
💡 This is a one-time step per device/browser. Your admin gives you the API key once (share it via WhatsApp or Signal, never email). Paste it here and click Connect — the app remembers it so you won't be asked again on this device. You will still need to log in with your username & password each session (or after clicking Sign out).
